## 学习笔记

### 数据类型与字符（day2）

- `char` 存的是字符的 **ASCII 码**（整数）：`'A'` = 65，`'a'` = 97，`'0'` = 48
- 同一字节两种读法：`%d` 看编号，`%c` 看字符
- 大小写转换用 `ch - 'A' + 'a'`（不要直接 `±32`，那依赖具体编码）
- `'a' - 'A'` = 32，每一对大小写字母都差 32

### scanf 与输入缓冲区

```c
scanf("%d %c", &i, &k);   /* 有空格：跳过空白，正确读到字符 */
scanf("%d%c",  &m, &n);   /* 无空格：%c 会把空格/换行吞掉 */
```

- `%c` **不跳过任何空白字符**，下一个是什么就读什么
- 排查技巧：把字符用 `%d` 打出来看 ASCII 码（空格 = 32、换行 = 10）
- 参考资料：输入缓冲区中残留的字符会影响下一次读取

### 函数与参数传递（ch6/swap）

- C 的函数调用是**值传递**：实参的值被**复制一份**给形参，函数里改的是副本
- 所以 `swap_by_value(a, b)` 交换不了 `main` 里的 `a`、`b`；要真交换必须传**地址**（指针）
- 一个函数**只能有一个返回值**，想带回多个结果就得靠指针或结构体
- `return` 的语义：把值送回调用处，同时结束当前函数

### 本地变量：作用域与生存期（ch6/localvar）

- **作用域** = 变量能"被看见"的范围，由它所在的那对 `{}` 决定
- 不同函数里的同名变量是**两份独立内存**，互不影响
- 内层块定义的变量会**遮蔽（shadow）**外层的同名变量；出了块就还原
- `for (int i = 0; ...)` 里的 `i` 也是块作用域，出了循环就不能用（编译报错）
- 未初始化的局部变量是**垃圾值**，`-Wall` 会给出 `used uninitialized` 警告
