# M2 · 韦东山 嵌入式 Linux 应用篇

### 1. Linux 基础命令（尚硅谷「Ubuntu快速上手」前置补丁）
- [ ] 绝对路径 vs 相对路径、家目录 `~`、当前目录 `.`
- [ ] 文件操作：`ls -l` / `cd` / `pwd` / `mkdir` / `cp` / `mv` / `rm` / `rmdir`
- [ ] 查看内容：`cat` / `more` / `less` / `head` / `tail` / `wc`
- [ ] 权限：`chmod`（数字法 755/644）、`chown`、`sudo` 提权
- [ ] 管道与重定向：`|` / `>` / `>>` / `<` / `grep`
- [ ] 查找：`find` / `which` / `locate`
- [ ] 进程：`ps` / `top` / `kill` / `jobs` / `&` / `fg`
- 👉 速查见 [[速查-Linux基础命令]]

### 2. vim 编辑器（每天练）
- [ ] 三种模式：普通 / 插入(`i a o O`) / 命令(`:`)
- [ ] 移动：`h j k l` / `w b e` / `0 $` / `gg G`
- [ ] 删除：`x` / `dw` / `de` / `d$` / `dd` / `3dw`
- [ ] 复制粘贴：`yy` / `p` / `3yy` / `yw`
- [ ] 撤销重做：`u` / `Ctrl-r`
- [ ] 保存退出：`:w` / `:wq` / `:q!` / `ZZ`
- [ ] 搜索替换：`/关键词` / `:s/old/new/g`
- 👉 速查见 [[速查-vim]]

### 3. gcc 编译（应用篇核心）
- [ ] 单文件：`gcc hello.c -o hello`
- [ ] 多文件编译（复用 C 的 [[速查-gcc与Makefile#多源文件编译]]）
- [ ] 常用参数：`-Wall -Wextra -g -O2 -I -L -l`
- [ ] 预处理/编译/汇编/链接 四阶段（`-E -S -c`）
- [ ] 头文件与库：`-I` 指定头文件路径、`-L`/`-l` 链接库
- 👉 速查见 [[速查-gcc与Makefile]]

### 4. Makefile（M1 ch12.2 多源文件地基直接复用）
- [ ] 基本规则：`target: prerequisites` + 命令（Tab 缩进！）
- [ ] 变量：`CC = gcc`、`CFLAGS = -Wall -g`
- [ ] 自动变量：`$@ $^ $<`
- [ ] 伪目标：`.PHONY: clean`
- [ ] 多文件项目 Makefile 模板
- 👉 速查见 [[速查-gcc与Makefile#Makefile 速查]]

### 5. 文件 IO（应用层重点，对照 C 仓库 `ch19`）
- [ ] 标准库 IO：`fopen/fclose/fread/fwrite/fprintf/fgets`（C 已学）
- [ ] **系统调用 IO**：`open/close/read/write/lseek`（`man 2 open`）
- [ ] 文件描述符 fd 概念（0=stdin 1=stdout 2=stderr）
- [ ] 文本 vs 二进制、阻塞读写
- [ ] `stat` / `fcntl` / `dup2` 初识
- 👉 速查见 [[速查-文件IO]]
