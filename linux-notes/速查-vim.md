# 速查 · vim

> 配合 [[M2-韦东山应用篇#2 vim 编辑器]] 使用。vim 的核心是「模式」。拿不准就按 `Esc` 回普通模式。

## 三种模式
- **普通模式**（默认）：按命令移动/删除/复制
- **插入模式**：`i` / `a` / `o` / `O` 进入，打字，按 `Esc` 退出
- **命令模式**：普通模式下按 `:` 输入命令

## 移动光标（普通模式）
```vim
h j k l        " 左 下 上 右
w / b          " 跳到下一个/上一个 单词开头
e              " 跳到本单词结尾
0 / ^          " 行首(0含缩进 ^不含)
$              " 行尾
gg / G         " 文件首行 / 末行
:n             " 跳到第 n 行
Ctrl+f / b     " 下翻/上翻一屏
```

## 删除（d = 操作符，后面接范围）
```vim
x              " 删光标处字符
dw             " 删到下一个词首(含后面空格)
de             " 删到本词尾(留空格)   ← 你刚学的
d$ / D         " 删到行尾
dd             " 删整行
3dd            " 删3行
d2w            " 删2个单词
```

> [!note] dw vs de（你问过的）
> `w`=下一词开头（跨过词+空格），`e`=本词结尾（留空格）。想干净连起来用 `dw`，只抠词用 `de`。

## 复制粘贴
```vim
yy / Y         " 复制整行
yw             " 复制一个单词
p / P          " 粘贴到光标后 / 前
3yy            " 复制3行
```

## 撤销重做
```vim
u              " 撤销
Ctrl+r         " 重做
```

## 保存退出（命令模式，先按 :）
```vim
:w             " 保存
:wq / ZZ       " 保存并退出
:q!            " 不保存强制退出
:w newfile     " 另存为
```

## 搜索替换
```vim
/word          " 向下搜 word，n 下一个 N 上一个
?word          " 向上搜
:s/old/new/    " 当前行替换第一个
:%s/old/new/g  " 全文替换所有
```

## 实用
```vim
v / V          " 字符/行 可视化选择(配合 d/y 很香)
Ctrl+v         " 列块选择
>> / <<        " 缩进/反缩进
:set nu        " 显示行号
:%s/\s\+$//g   " 删掉所有行尾空格
```
