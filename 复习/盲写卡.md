## 阶段一：必刷 ★（致命 / 段错误 / 高频，优先回刷）

### ★1. 手写字符串拷贝 my_strcpy（返回目标串首地址）
- **盲写**：`char* my_strcpy(char* dest, const char* src)`，不用库函数，把 src 拷到 dest，返回 dest。
- **验收**：`my_strcpy(b,a)` 后 `b` 内容与 `a` 一致；返回值是 `b` 的首地址。
- **回看**：BUG.md #1（返回类型必须是 `char*`）；旧代码 `ch12/practice2/my_strcpy.c`

### ★2. 手写字符串比较 my_strcmp
- **盲写**：`int my_strcmp(const char* s1, const char* s2)`，逐字符比，返回首对差异字符的 ASCII 差值（相等返 0）。
- **验收**：`"abc"` vs `"abd"` 返负值；`"ab"` vs `"abc"` 返负值；相同返 0。
- **回看**：BUG.md #2（形参 `char*` 不是 `char*[]`；用 `&&` 不是 `&`；返回差值不是 0/1）；`ch12/practice3/my_strcmp.c`

### ★3. 位运算四件套：置/清/翻/取第 n 位
- **盲写**：用 `num` 和第 n 位（n 从 0 起）写出 ①置位 ②清位 ③翻转 ④取该位值 四行。
- **验收**：设 `num=0b1010`，清第 1 位后应得 `0b1000`；取第 3 位得 1。
- **回看**：BUG.md #7（**清位必须 `&= ~(1u<<n)`，漏 `~` 就错**）；`ch14/practice1/bits.c`

### ★4. 带参宏 SQR 的双括号 + 副作用
- **盲写**：写 `#define SQR(x) ...` 让 `SQR(a+1)` 得 `(a+1)²`；并说明「为什么不能传 `SQR(++i)`」。
- **验收**：`SQR(a+1)` 展开后每个参数和整体都被括号包住；能口述「宏是文本替换，++i 会被替换多次 → 未定义行为」。
- **回看**：BUG.md #13（参数加括号 + 整体加括号 + 不传副作用）；`ch16/practice1/test.c`

### ★5. 状态机：外层 switch(状态) + 内层 if(事件)
- **盲写**：定义两个枚举 `IDLE/RUN` 和事件 `START/STOP`，用状态机实现「IDLE 收到 START→RUN；RUN 收到 STOP→IDLE」。
- **验收**：绝不出现 `switch(s+e)` 或 `state==s+e` 这类相加判断；两个维度分开。
- **回看**：BUG.md #10（**状态+事件绝不相加**，这是致命坑）；`ch15/practice2/state.c`

### ★6. 链表尾插找尾：循环条件
- **盲写**：写 `tail_insert(Node** head, int n)` 把新节点接到链表**末尾**（注意空表分支 + 找尾循环条件）。
- **验收**：输入 1 2 3 尾插，遍历打印 `1 2 3`；非空表不崩。
- **回看**：BUG.md #17（**找尾用 `while(p->next!=NULL)`，用 `p!=NULL` 会段错误**）；`ch18/practice4/insert.c`

### ★7. 综合项目 add() 必须入库
- **盲写**：写一个「添加学生到全局数组」的函数片段，填好结构体后必须让数组真正多出一条。
- **验收**：函数末尾有 `stulist[stucount]=s; stucount++;`（或等价），否则列表始终空。
- **回看**：BUG.md #20（**填完结构体别忘了入库那两行，否则保存是空文件**）；`ch19/practice6/student.c`

## 阶段二：普通 [偶尔忘]（隔周刷）

### 8. 结构体最大值标杆
- **盲写**：结构体数组找最高分，标杆用变量 `max` 而非 `arr[0]` 当下标。
- **验收**：标杆初值取 `arr[0]`，循环 `if(arr[i].score>max.score) max=arr[i]`。
- **回看**：BUG.md #5；`ch13/practice3/stats.c`

### 9. 指针遍历结构体数组（别漏 p++）
- **盲写**：`S* p=a;` 遍历 n 个结构体，用 `->` 访问成员，必须显式前进。
- **验收**：循环体里有 `p++` 或 `p=a+i`，否则只处理第一个/死循环。
- **回看**：BUG.md #6；`ch13/practice4/typedef.c`

### 10. 判断奇偶（别多挂 num>0）
- **盲写**：判断一个 int 是奇是偶，与正负无关。
- **验收**：`if(num&1)` 奇数；负奇数也能正确判。
- **回看**：BUG.md #8；`ch14/practice3/parity.c`

### 11. 节点结构不能自我包含
- **盲写**：让链表节点「存一个 int 数据 + 指向下一节点」，写出正确结构定义。
- **验收**：数据字段用**别的**类型（如 `int data`），下一个节点才用 `struct Node* next`；不出现 `struct Node stu;` 这种值成员。
- **回看**：BUG.md #15（**节点里放数据用其他类型，放下一节点才用 `struct Node*`**）；`ch17/practice3/choose.c`

### 12. 文件读回显：打 buf 不越界
- **盲写**：`fgets(buf,...)` 读完文件后，把内容正确打印出来验证「读到的==写入的」。
- **验收**：`while(fgets(buf,sizeof(buf),fp)!=NULL) printf("%s",buf);`；不打印越界数组下标。
- **回看**：BUG.md #19；`ch19/practice1/read.c`

### 13. loadfile 关闭后置空用单等号
- **盲写**：`fclose(fp);` 之后把 `fp` 置空，写出正确的一行。
- **验收**：`fp=NULL;`（单等号赋值），不是 `fp==NULL;`（双等号比较，无效）。
- **回看**：BUG.md #22；`ch19/practice6/student.c`

### 14. 自定义类型先定义后使用
- **盲写**：写一个用到 `struct S` 的 swap 函数，结构定义位置正确（不报 unknown type）。
- **验收**：`typedef struct {...} S;` 放在所有函数原型和函数体**之前**。
- **回看**：BUG.md #4 + 通用铁律第一条；`ch13/practice2/modify.c`

## 盲写纪律（务必遵守，否则无效）
1. **先写后看**：没写出最小可运行版之前，不打开 BUG.md 答案、不翻旧代码。
2. **编译验证**：写错比写不出更值钱——编译器报错能精确定位你哪根筋没接上。
3. **标记状态**：刷完在题号前打 ✅（真记住）/ ⚠️（还卡），⚠️ 的回 BUG.md 把 `[已掌握]` 改回 `[偶尔忘]`。
4. **频率**：周六复盘抽 4–6 题；考前（春招）全卡过一遍。
